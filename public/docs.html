1 Persiapan

Langkah pertama yang harus kamu lakukan adalah mendaftar dan login ke dashboard. Setelah itu, dapatkan API Key kamu di menu Profil untuk mulai mengintegrasikan sistem pembayaran ke aplikasi kamu.

Simpan API Key Anda di tempat yang aman. Jangan bagikan ke siapa pun. Jika bocor, segera generate ulang di menu Profil.
Base URL: http://localhost:3000 (ganti dengan domain Anda saat produksi)
Autentikasi: ?apikey=YOUR_API_KEY atau header X-API-Key

3 Membuat Invoice

NamaTipeWajibKeterangan

  `${baseUrl}/api/createinvoice?apikey=${apiKey}&amount=50000`

Gunakan nilai payment_link atau qris_image untuk menampilkan halaman pembayaran kepada customer.

5 Webhook

Webhook memungkinkan sistem Anda menerima notifikasi real-time ketika ada transaksi deposit yang berhasil dibayar (status paid) — tanpa perlu melakukan polling ke API kami.

Setup Webhook

Aktifkan webhook di halaman Profil:

Format Request yang Kami Kirim

POST <URL webhook Anda>
Content-Type: application/json
X-Webhook-Event: deposit.paid
X-Webhook-Id: <log_id>
X-Webhook-Attempt: 1
User-Agent: Vincent Pay-Webhook/1.0

Body (JSON Payload)

{
  "event": "deposit.paid",
  "created_at": "2025-01-01T12:00:00.000Z",
  "data": {
    "id": "TRX...",
    "reference": "TRX...",
    "type": "deposit",
    "amount": 10000,
    "fee": 123,
    "total": 10123,
    "status": "paid",
    "qris_image": "https://...",
    "created_at": "2025-01-01T11:55:00.000Z",
    "completed_at": "2025-01-01T12:00:00.000Z",
    "balance_after": 10123
  }
}

Response yang Kami Harapkan

  • HTTP 2xx → dianggap sukses, selesai
  • Selain 2xx atau timeout (15 detik) → otomatis retry

Kebijakan Retry Otomatis

Total 5 percobaan dengan jeda bertingkat: 1 menit → 5 menit → 15 menit → 1 jam → 6 jam. Anda juga bisa melakukan retry manual dari halaman Riwayat Webhook.

Contoh Handler (Node.js / Express)

const express = require('express');
const app = express();

app.use(express.json());

app.post('/webhook', (req, res) => {
  const event = req.body.event;

  if (event === 'deposit.paid') {
    const data = req.body.data;
    console.log('💰 Deposit paid:', data.id, data.amount);

    // TODO: update saldo user di sistem Anda
  }

  // Selalu balas 200 agar dianggap sukses
  res.status(200).json({ ok: true });
});

app.listen(3000);

Pastikan endpoint Anda selalu membalas HTTP 2xx secepat mungkin (idealnya < 5 detik). Jika butuh proses lama, simpan payload dulu lalu proses di background (queue) agar tidak timeout.
